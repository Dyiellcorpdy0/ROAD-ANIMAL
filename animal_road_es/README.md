# Система распознавания животных на дороге (прототип ЭС)

Прототип экспертной системы для ЛР №6 по дисциплине
«Технологии и инструментальные средства проектирования интеллектуальных систем».

## Установка

```bash
pip install -r requirements.txt
```
Запуск
```bash
python app.py
```
Принцип работы
Камера передаёт видеопоток.

YOLOv8 обнаруживает животных (лось, олень, кабан, собака).

PositionInterpreter определяет положение животного в зоне дороги/обочины.

InferenceEngine по правилам resources/rules.json определяет риск.

SignOutput окрашивает круг-имитатор лампы:

зелёный — дорога свободна;

жёлтый — животное на обочине;

красный — животное на проезжей части.

Тестовые режимы
Без камеры → демо-режим (тёмный кадр с надписью).

Без YOLOv8 → детектор возвращает пустой список.

Что изменить для реального знака
В sign_output.py метод set_color_hardware() — подключить GPIO/CAN.

# ✅ Быстрый старт

1. Создать структуру папок и файлов из списка выше.
2. Поместить файлы `rules.json`, `config.json`, `animal_road_ontology.owl` в `resources/`.
3. Выполнить `pip install -r requirements.txt`.
4. Запустить `python app.py`.

**При первом запуске** YOLOv8 скачает `yolov8n.pt` (~6 МБ) в папку `models/`.

## 🎬 Подключение видеофайла

Вместо камеры можно использовать записанное видео:

1. Положите видеофайл (`.mp4`, `.avi`, `.mov`) в папку `resources/videos/`.
2. Откройте `resources/config.json` и укажите путь в поле `video_source`:
   ```json
   "video_source": "resources/videos/demo.mp4"
   ```
3. Сохраните и запустите `python app.py`. Видео будет зацикливаться автоматически.

Оставьте `video_source` пустым (`""`), если нужно использовать веб-камеру (`camera_index`).

## 💡 Проверка системы

| Сценарий | Что делать | Ожидаемый результат |
|----------|-----------|---------------------|
| Демо без камеры | Запустить без подключённой камеры | Открывается окно, лампа **зелёная**, объекты не обнаруживаются |
| Собака в кадре (COCO) | Показать камеру на собаку/картинку с собакой | Собака обнаружена; в зависимости от зоны — **жёлтый/красный** |
| Без объектов | Камера в пустоту | Лампа **зелёная**, объектов 0 |
| Нажатие «Объяснение» | Нажать кнопку | Показ правила, которое сработало |
